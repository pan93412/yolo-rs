# Prebuilt yolo-cli binaries

Each GitHub release now carries yolo-cli for Linux (x86_64 and arm64) and macOS (Apple silicon, signed and notarized), so you can try a model without installing Rust: `curl -L https://github.com/pan93412/yolo-rs/releases/latest/download/yolo-cli-aarch64-apple-darwin.tar.gz | tar -xz`. See "Try it without Rust" in the README.
